# Project 3: Interactive Web Elements

A clean, responsive, and interactive web application built with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features

* **Interactive Counter:** Real-time state management allowing users to increment, decrement, and reset count values.
* **Dynamic Task Generator:** Safe creation of DOM elements dynamically with input validation.
* **XSS Protection:** Implements safe node creation methods (`textContent`) to prevent malicious script injection.
* **Theme Switcher:** Seamless toggle between Light and Dark themes for improved visual accessibility.

## 🛠️ Tech Stack

* **HTML5:** Semantic structural markup.
* **CSS3:** Custom styling, Flexbox layout, CSS variables, and modern dark mode styling.
* **JavaScript (ES6+):** Event handling, DOM manipulation, and dynamic node rendering.
